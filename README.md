# Editable Wokaya portfolio

Open dist/index.html in your browser to view the completed one-page site.

Edit dist/index.html for text, links, services and project cards. Edit dist/style.css for colors, typography and layout. Edit dist/app.js for animations, search and filters. All files are plain HTML, CSS and JavaScript; no build tools are required.

Website screenshots are in dist/assets/projects. Replace an image with a new screenshot using the same filename to refresh a preview. The portfolio contains 48 project links and 45 real website previews. Venati and the unnamed Shopify store are password-protected. The PAS Bluehost site has a certificate error, so those three cards use an honest preview-unavailable treatment.

Upload the contents of dist to any static hosting provider. The current Sites project configuration is in .openai/hosting.json.
